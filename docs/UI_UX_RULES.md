# UI/UX 규칙

## 정보 구조

상단 네비게이션은 PRD 기준으로 `홈`, `백테스트`, `커뮤니티`를 기본으로 합니다. `내 정보`는 MVP 제외 범위이므로 비활성 상태로 두거나 구현하지 않습니다.

## 홈

- 주요 전략 템플릿을 첫 화면에서 보여줍니다.
- 최근 인기 전략과 금일 시황은 목업 데이터일 경우 명시합니다.
- 주 액션은 백테스트 시작입니다.

## 백테스트

백테스트 화면은 세 영역을 유지합니다.

- 전략 목록 사이드바: 전략 추가, 저장된 전략 선택
- 전략 편집 사이드바: 이름, 수정 시간, 전략 조건, 템플릿, 옵션
- 결과 영역: 실행 전 빈 상태, 실행 후 지표와 차트

전략 조건은 매수 조건과 매도 조건을 구분합니다. 실행 버튼은 매수/매도 조건이 유효할 때만 활성화합니다.

## 결과 화면

결과 화면은 다음 순서를 우선합니다.

1. 핵심 지표 카드: 총수익률, CAGR, MDD, Sharpe
2. 수익률 차트와 벤치마크 비교
3. 성과 요약
4. 수익률 분포, 월별 수익률, 거래 요약
5. 결과 공유

MDD가 크거나 거래 횟수가 부족하면 경고를 표시합니다.

## 커뮤니티

MVP에서는 실제 사용자 계정 없이 샘플 전략 리스트로 시작합니다. 좋아요, 댓글, Fork는 UI 힌트만 두고 실제 쓰기 기능은 후순위로 둡니다.

## 사용성 규칙

- 사용자가 다음에 무엇을 해야 하는지 명확해야 합니다.
- 지표명에는 툴팁 또는 짧은 설명을 제공합니다.
- 목업 데이터와 실제 데이터를 시각적으로 구분합니다.
- 테이블은 정렬 기준과 단위를 명확히 표시합니다.
- 모바일에서는 사이드바가 접히거나 상단/하단 패널로 전환되어야 합니다.

## 접근성

- 버튼은 실제 `button` 요소를 사용합니다.
- 아이콘 버튼에는 `aria-label` 또는 `title`을 제공합니다.
- 차트는 핵심 수치를 텍스트로도 제공합니다.
- 색상만으로 상승/하락 또는 위험을 전달하지 않습니다.
