# 제품 규칙

## 제품 정의

검투사는 개인 투자자가 코딩 없이 투자 전략을 만들고 과거 데이터로 검증하는 백테스팅 플랫폼입니다. 핵심 가치는 쉬운 전략 설계, 빠른 백테스트, 신뢰 가능한 성과 분석, 전략 비교와 공유입니다.

## MVP 포함 범위

- 단일 전략 백테스트
- 기본 기술지표 기반 조건 빌더
- 성과 차트와 주요 지표 카드
- 전략 템플릿 제공
- 커뮤니티 읽기/탐색 경험
- 로컬 또는 임시 저장 기반 전략 저장

## MVP 제외 범위

- 로그인과 계정 시스템
- AI 전략 추천
- 실시간 자동매매
- 암호화폐 백테스트
- 실제 결제, 구독, 유료 플랜
- 투자 자문 또는 매수/매도 추천 표현

## 우선순위

1. 정적 UI와 목업 데이터로 전체 사용자 흐름 검증
2. 전략 조건 JSON 스키마 고정
3. 백테스트 요청/응답 포맷 고정
4. 단일 종목 일봉 백테스트 구현
5. 결과 차트와 지표 카드 연결
6. 로컬 저장 기반 전략 저장
7. 커뮤니티는 읽기 전용 샘플 리스트로 시작

## 기능 판단 기준

- 사용자가 전략을 더 쉽게 만들 수 있는가?
- 결과를 더 신뢰하고 해석할 수 있는가?
- MVP 흐름을 복잡하게 만들지 않는가?
- 데이터나 계산의 한계를 사용자에게 숨기지 않는가?

## 금지 표현

- "수익 보장", "무조건 상승", "추천 종목", "따라 사세요" 같은 투자 자문성 문구
- 백테스트 성과를 미래 수익으로 단정하는 표현
- 데이터 결측 또는 목업 데이터를 실제 검증처럼 보이게 하는 표현

## 결과 안내 문구 기준

백테스트 결과 화면에는 다음 정보가 함께 표시되어야 합니다.

- 데이터 출처 또는 목업 데이터 여부
- 테스트 기간
- 수수료와 슬리피지 적용 여부
- "백테스트 결과는 투자 조언이 아니며 과거 성과가 미래 수익을 보장하지 않습니다."라는 취지의 안내
