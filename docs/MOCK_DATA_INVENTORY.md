## 5. 전략 템플릿 기본값

파일: `app.js`

템플릿 자체는 제품 기능으로 유지 가능하지만, 기본 백테스트 기간과 성과는 실제 데이터로 재계산해야 합니다.

| 요소 | 현재 값 | 교체 방향 |
| --- | --- | --- |
| `strategies` 기본 템플릿 | 코드 내 정적 배열 | 서버/정적 JSON/DB 중 하나로 분리 |
| `startDate` | `2020-01-01` | 사용자 선택값 또는 템플릿 기본값 |
| `endDate` | `2025-12-31` | 실제 데이터 최신일 이하 |
| 안정형 포트폴리오 종목 | `VTI`, `VXUS`, `BND`, `TLT`, `IEF`, `SHY`, `GLD`, `DBC`, `VBR` | 실제 ETF OHLCV 데이터 연동 |

## 8. 실제 데이터 전환 시 우선순위

1. `marketData`와 `generateMockPrices()`를 데이터 로더 인터페이스로 교체
2. 백테스트 결과의 `dataMode`, `dataSource`, 기준일, 결측 경고 실제화
3. 지수 UI와 홈 금일 시황 실제 데이터 연동
4. 종목 검색/선택 후보를 실제 종목 마스터로 교체
5. 커뮤니티/랭킹/토론 샘플 데이터를 실제 API로 교체
6. 템플릿 카드 성과 수치를 실제 백테스트 결과로 재계산
