# 검투사 MVP 추가 추천 사항

PRD 기준 MVP에 이미 포함된 범위는 단일 전략 백테스트, 기본 기술지표, 성과 차트, 전략 템플릿, 커뮤니티입니다. 아래 항목은 구현 난이도 대비 검증 가치가 높은 보강안입니다.

## 1. 백테스트 신뢰도 표시

- 데이터 기준일, 데이터 출처, 결측치 여부를 결과 화면에 표시
- 수수료와 슬리피지 적용 여부를 지표 카드 근처에 노출
- 백테스트 결과가 투자 조언이 아니라는 안내 문구 추가

## 2. 전략 유효성 체크

- 매수 조건과 매도 조건이 비어 있을 때 실행 방지
- 동일 조건 중복 추가 방지
- 과도하게 짧은 테스트 기간, 거래 횟수 부족, 특정 종목 편중 경고

## 3. 벤치마크 기본 비교

- 한국 시장은 KOSPI 또는 KOSDAQ
- 미국 시장은 S&P 500 또는 NASDAQ
- ETF 전략은 SPY 또는 선택 ETF를 기본 벤치마크로 제공

## 4. 예시 데이터 모드

- 실제 API 연동 전에도 체험 가능한 목업 데이터 세트 제공
- SPY, QQQ, 삼성전자, KOSPI ETF 등 대표 종목을 우선 포함
- 데이터 로딩 실패 시 예시 데이터로 전환하는 안내 제공

## 5. 저장 전 공유 기능

- 로그인 제외 MVP에서도 URL 파라미터 또는 로컬 저장소 기반 임시 공유 지원
- 전략 조건, 기간, 초기 자본, 결과 요약을 공유 카드 형태로 복사

## 6. 결과 해석 보조

- CAGR, MDD, Sharpe 같은 지표에 짧은 툴팁 제공
- 성과가 좋아도 MDD가 큰 경우 리스크 경고 표시
- 벤치마크 대비 초과수익과 최대 낙폭을 함께 보여주기

## 7. MVP 우선순위 제안

1. 정적 UI와 목업 데이터로 전체 사용자 흐름 검증
2. 전략 조건 JSON 스키마 정의
3. 백테스트 엔진 입력과 출력 포맷 고정
4. 단일 종목 일봉 백테스트 구현
5. 결과 차트와 지표 카드 연결
6. 로컬 저장 기반 전략 저장
7. 커뮤니티는 읽기 전용 샘플 리스트로 시작

## 8. 초기 데이터 모델 후보

- Strategy: 이름, 설명, 시장, 매수 조건, 매도 조건, 백테스트 옵션, 공개 여부
- BacktestRun: 전략 ID, 실행 시간, 입력 파라미터, 결과 요약, 차트 데이터
- CommunityStrategy: 전략 ID, 작성자명, 좋아요 수, 복제 수, 공개 상태
- TradeLog: 실행 ID, 종목, 매수일, 매도일, 수익률, 보유 기간
