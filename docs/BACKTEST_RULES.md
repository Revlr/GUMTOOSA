# 백테스트 규칙

## MVP 범위

MVP 백테스트는 단일 전략, 단일 종목, 일봉 데이터 기준으로 시작합니다. 포트폴리오, 월간 리밸런싱, 다중 전략 비교는 결과 포맷이 안정화된 뒤 확장합니다.

## 입력

백테스트 엔진 입력은 `STRATEGY_SCHEMA.md`의 `Strategy`와 `BacktestOptions`를 따릅니다. 엔진 내부에서 UI 전용 필드를 참조하지 않습니다.

## 실행 기준

- 매수 조건이 참이고 보유 중이 아니면 매수합니다.
- 매도 조건이 참이고 보유 중이면 매도합니다.
- 동일 날짜에 매수와 매도가 동시에 참이면 보수적으로 매도를 우선합니다.
- 체결가는 MVP에서 다음 거래일 시가 또는 당일 종가 중 하나로 고정하고 결과에 명시합니다.
- 수수료와 슬리피지는 모든 거래에 적용합니다.

## 지표 계산 기준

- 총수익률: `(최종 자산 / 초기 자본) - 1`
- CAGR: 테스트 기간을 연 단위로 환산해 계산
- MDD: 고점 대비 최대 하락률
- 변동성: 일간 수익률 표준편차를 연율화
- Sharpe: 무위험 수익률은 MVP에서 0으로 두고, 추후 설정 가능하게 분리
- 승률: 수익 거래 수 / 전체 청산 거래 수

## 경고 기준

다음 상황은 결과에 `warnings`로 포함합니다.

- 테스트 기간이 6개월 미만
- 거래 횟수가 5회 미만
- 결측 데이터가 존재함
- MDD가 30%보다 큼
- 목업 데이터로 실행됨
- 벤치마크 데이터가 없어 비교하지 못함

## 신뢰도 표시

결과 화면은 데이터 출처, 데이터 기준일, 결측치 여부, 수수료/슬리피지 적용 여부를 표시해야 합니다.
