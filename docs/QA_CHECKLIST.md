# QA 체크리스트

기능을 완료하기 전에 아래 항목을 확인합니다.

## 제품 범위

- [ ] MVP 제외 범위인 로그인, AI 추천, 실시간 자동매매를 추가하지 않았다.
- [ ] 기능이 "전략 생성 -> 실행 -> 결과 해석 -> 저장/공유" 흐름에 맞다.
- [ ] 목업 데이터와 실제 데이터 여부가 표시된다.

## 전략 빌더

- [ ] 매수 조건과 매도 조건이 각각 최소 1개 이상 있어야 실행된다.
- [ ] 동일 조건 중복 추가를 막는다.
- [ ] AND/OR 조건이 저장과 실행에 동일하게 반영된다.
- [ ] 전략 이름과 마지막 수정 시간이 갱신된다.

## 백테스트

- [ ] 시작일이 종료일보다 앞선다.
- [ ] 수수료와 슬리피지가 결과에 반영된다.
- [ ] CAGR, MDD, Sharpe, 총수익률 계산 기준이 문서와 일치한다.
- [ ] 거래 횟수 부족, 짧은 기간, 결측 데이터 경고가 표시된다.
- [ ] 결과가 투자 조언이 아니라는 안내가 있다.

## UI

- [ ] 데스크톱과 모바일에서 텍스트가 겹치지 않는다.
- [ ] 주요 버튼은 키보드로 접근 가능하다.
- [ ] 아이콘 버튼에는 이름이 있다.
- [ ] 차트 핵심 수치가 텍스트로도 제공된다.
- [ ] 상승/하락/위험 상태가 색상만으로 전달되지 않는다.

## 데이터

- [ ] 날짜 형식은 `YYYY-MM-DD`다.
- [ ] 데이터 출처와 기준일을 표시한다.
- [ ] 외부 데이터 실패 시 목업 데이터 전환을 안내한다.
- [ ] 벤치마크 데이터가 없으면 비교 불가 상태를 표시한다.

## 회귀 확인

- [ ] 홈, 백테스트, 커뮤니티 화면 전환이 동작한다.
- [ ] 전략 선택 시 결과 제목과 편집 이름이 일치한다.
- [ ] 실행 버튼 클릭 시 결과 영역 상태가 갱신된다.
- [ ] 저장 또는 공유 기능이 있다면 새로고침 후 동작을 확인했다.
